# Cocoa Studio repo

This repo is Cocoa Creative's studio toolkit (a Claude plugin in `skills/`) plus client files in `clients/<slug>/`. Follow `skills/studio-standards/SKILL.md` for all client work.

- Client-facing pages go to the separate `CocoaCreates/cocoa-previews` repo, never here.
- Never email clients or prospects. Terrence handles all outreach.
- Keep `client.json` valid JSON. Append to `notes.md`; never rewrite history.
- Commit messages start with the client slug, for example `uta: …`.
