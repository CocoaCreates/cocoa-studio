# Graphic formats

| Graphic | Canvas | Use |
|---|---|---|
| Game day post | 1080×1350 | IG/FB feed |
| Final score | 1080×1080 | All platforms |
| Starting five | 1080×1350 | Pregame |
| Halftime / box stats | 1080×1350 | In-game social |
| Player of the game | 1080×1350 | Postgame |
| Story / Reel cover | 1080×1920 | Stories, Reels, TikTok |
| X / Twitter | 1600×900 | Feed |
| Email newsletter header | 1200×400 (render @2x) | Next-game promo, ticket push |
| Website hero | 1920×800 | Athletics site |
| Team announcement | 1080×1080 | Schedule release, signing, milestone, record |
| Countdown | 1080×1350 | "3 days to tip-off" series |
| Sponsor thank-you | 1080×1080 | Partner recognition post |
| Broadcast lower-third | 1920×1080 transparent PNG | Streaming |

Copy tone: short and loud on the graphic, with details in the caption. Pair the uppercase display face with the body face for details.
